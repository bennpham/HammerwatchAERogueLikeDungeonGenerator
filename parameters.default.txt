# Lobbies (issue #48): hand-authored shop rooms, any number of them, each
# independently placed by levelOrder below. `lobbies` is how many the
# campaign has; every other lobby key carries its lobby's index directly
# after `lobby`, the same way boss keys carry a fight index — lobby0Preset is
# the first lobby's, and a third lobby adds a full lobby2* block. There is no
# unprefixed spelling and no "disabled" lobby: one exists iff it is in this
# list, and a lobby that used to be off is simply absent.
#
# lobby<i>Preset picks which committed room this lobby edits — BETA-dungeon-prep
# (the campaign's original starting lobby) or BETA-boss-prep (the room that
# used to be welded to the front of every boss fight, now just another lobby).
# lobby<i>Gold is a multiple of 500 (one red diamond each); more diamonds than
# the room has spots simply stack on the same spots. lobby<i>Shops is the
# space-separated list of shop columns its stalls sell. lobby<i>Upgrades is the
# same eight free-upgrade counts as before, in the order damage defense health
# mana damage2 defense2 health2 mana2 (the 2s are the game's own second-tier
# items); each kind has one spot in the room, so a count above one stacks
# there, and 0 lays none of that kind out at all.
#
# The stock campaign carries two: the dungeon-prep lobby at the very start,
# and the boss-prep lobby right before the fight — see levelOrder below.
#
# lobbySaves is campaign-wide: 1 puts a save checkpoint by every lobby's exit
# (items/trigger_button_save.xml), 0 emits each lobby exactly as authored. It
# moves no dungeon floor — only the lobby files gain the one item. Defaults on.

# levelOrder is the order the campaign is PLAYED in: dungeon floors by their
# 1-based number, arenas as AB1, AB2, ... (a boss fight) or AS1, AS2, ... (a
# survival round), and lobbies as L1, L2, ...
# e.g. levelOrder=L1,1,AB1,3,4,AS2, or levelOrder=AB1,1,2,3 to open on a boss
# fight. Unlike before issue #48, a fight is only ever ONE level (its arena) —
# a shop in front of it is a separate lobby entry, placed next to it here.
#
# An arena's NUMBER is its position in the fight list, so one boss arena and
# one survival arena read AB1, AS2 — the prefix says which mode it is, and
# flipping a mode changes one letter and renumbers nothing. The prefix is
# informational: B1 (the old spelling), AB1 and AS1 all name the same slot, and
# boss<i>Mode below is what actually decides the mode.
#
# Floors keep their own order, and so do fights, and so do lobbies (2 can
# never come before 1 within its own kind); only how the three interleave is
# free. Whichever entry is LAST holds the victory orb, so a campaign can
# equally well end on a dungeon floor — but a lobby may never be last, since it
# has no orb of its own.
#
# Omit the key for the default order — every lobby, then every floor, then
# every boss fight. The stock campaign is NOT that order (it would put both
# lobbies ahead of every floor): floor 8 is the escape floor, played after the
# boss arena, and the boss-prep lobby sits right before the fight rather than
# at the very front, so it is written out below.
